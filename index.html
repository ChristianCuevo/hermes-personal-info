Personal assistant

Hermes Personal

A privately operated assistant for email, scheduling and daily administration.

What it does

Hermes Personal is a personal installation of the open-source Hermes Agent software, used by its owner through a private Telegram conversation. It can find and summarize Gmail messages, review Google Calendar events, and prepare proposed email replies or event changes. Email sending and calendar changes are not currently enabled.

After additional Google consent, the integration supports archiving selected messages and creating or removing automatic archive filters. Each archive action or filter change requires the owner's explicit approval in a private Telegram approval conversation. Approved filters then run automatically in Gmail until removed; creating a filter does not clean up existing mail.

The base Google connection requests permission to read Gmail, send Gmail messages, and view or edit calendar events. Optional inbox management adds Gmail modify and basic settings permissions. Granted permissions may be broader than the actions currently enabled. This installation is intended for its owner's personal use.

How it operates

The assistant runtime and its working data are hosted on the owner's DigitalOcean server. OpenAI provides cloud model inference. Telegram carries the owner's conversations and notifications. Relevant Google data may be processed by these services when needed to fulfill the owner's requests.

This public site describes the application and its data practices. It is separate from the private agent runtime.
